The Billy consumption panel provides comprehensive real-time visibility into your billing consumption with advanced filtering capabilities and administrative insights. This floating panel appears in the bottom-left corner of your dashboard when billing rules are configured.

<Info>
The Billy panel automatically appears when you have billing rules configured for your account. If you don't see it, contact your administrator to set up billing configuration.
</Info>

## Panel Overview

The enhanced Billy consumption panel displays:

- **Minutes package progress bar** for accounts with a contracted monthly allowance
- **Rules-v2 balance block** for accounts on the newer billing engine, showing either a committed tier's progress or a prepaid bag's available units
- **Real-time consumption data** with intelligent period detection
- **Advanced filtering system** with a dropdown period selector and custom date ranges
- **Cost breakdown by assistant** with detailed unit metrics
- **Administrative historical charts** for trend analysis
- **Billing adjustments** including minimums and corrections
- **Rotating message ticker** while the panel is collapsed
- **Flexible view modes** for different user types

## Minutes Package Progress Bar

For client accounts whose Billy billing profile has a **contracted monthly minutes allowance** configured, the expanded panel displays a dedicated "Minutes package" card positioned above the filters and consumption breakdown.

### When It Appears

<Info>
This card is only rendered when the consumption response includes a `minutes_package` object for the current profile — that is, when the account's Billy billing profile has a monthly minutes allowance explicitly configured. Accounts billed on a pure per-unit basis, with no contracted package, will never display this card, regardless of how much they've consumed.
</Info>

Because the card's visibility depends entirely on the billing profile configuration, it will appear or disappear consistently across every period you select — switching periods does not add or remove the card, it only updates the figures inside it.

### What It Shows

The card header displays the exact consumption figures for the selected billing period, formatted as:

```
X / Y min
```

Where `X` is the number of minutes consumed so far and `Y` is the total number of minutes contracted for the period. Both values are shown with locale-aware number formatting for readability.

Below the header, a **horizontal progress bar** fills proportionally to the usage percentage (`consumed / contracted`), with a smooth transition animation whenever the underlying data changes — for example, after a manual refresh or a period switch.

A short **footer message** provides context depending on the current status:

- **Within allowance**: shows the exact number of minutes still available for the rest of the billing period (`contracted − consumed`)
- **Over allowance**: shows the exact number of minutes exceeded beyond the contracted package (`consumed − contracted`)

<Steps>
<Step title="Card Renders">
When the selected period's data includes a minutes package, the card appears with the current consumed/contracted figures
</Step>
<Step title="Progress Bar Updates">
The bar fills according to the usage percentage returned by the server, animating smoothly between values
</Step>
<Step title="Status Color Applies">
The bar renders in emerald green while usage stays within the allowance, or switches to red the moment usage surpasses it
</Step>
<Step title="Footer Message Adjusts">
The footer text automatically switches between "remaining minutes" and "exceeded by" phrasing based on the allowance status
</Step>
</Steps>

### The Red Over-Allowance Indicator

When consumption exceeds the contracted allowance, the progress bar's fill color switches from emerald green to **red**, providing an immediate, unambiguous visual signal that the package has been surpassed.

<Warning>
The red indicator is purely visual. Exceeding the contracted minutes package does **not** stop call processing, block new calls, or interrupt any billing calculation. Consumption tracking and cost calculations below the card continue exactly as before — the red bar simply flags that usage is now beyond what was contracted, so the account should be reviewed or the package adjusted if needed.
</Warning>

<Info>
The over-allowance state is re-evaluated every time consumption data refreshes, whether triggered manually, by a period change, or by a custom date range. There is no separate "reset" action — the color and footer message always reflect the live comparison between consumed and contracted minutes for the currently selected period.
</Info>

## Balance Block for Rules-v2 Profiles

Accounts running on the newer **rules-v2** billing engine display a dedicated **balance block** instead of (or alongside) the minutes package card. This block adapts its layout depending on the type of contract configured on the account's Billy profile: a **committed volume tier** or a **prepaid bag**.

<Info>
The balance block only renders when the consumption response includes a `balance` object. Accounts on legacy per-unit rules without a rules-v2 contract will not see this block.
</Info>

### Committed Tier Variant

For accounts with a **committed volume tier** (a monthly contracted volume of minutes, seconds, or calls, billed at a specific tier price), the block shows:

- **Tier name**: The contracted tier's name, displayed next to the "Contracted volume" label whenever one is configured
- **Consumed vs. contracted units**: Formatted according to the unit type (for example, seconds are shown as minutes for readability)
- **Progress bar**: Fills proportionally to usage, always rendered in emerald — this variant does not use a red "over-allowance" color, since exceeding the tier is an expected, billable outcome rather than an error state
- **Footer message**: Shows one of two states depending on consumption:
  - **Within commitment**: the remaining units left in the monthly commitment
  - **Overage**: the exact overage in units, its equivalent monetary amount at the tier's price, and a note that it will be **billed next period**

<Warning>
Unlike the minutes package card, overage on a committed tier is **not** an alert. It represents genuine billable consumption charged at the same per-unit tier price, invoiced in the following billing cycle. The progress bar intentionally stays emerald in this state to avoid implying a problem.
</Warning>

### Prepaid Bag Variant

For accounts consuming from a **prepaid bag** (a pool of pre-purchased units), the block instead shows:

- **Available units**: The remaining balance of units left in the prepaid bag, labeled "Prepaid balance"
- **Consumed this period**: The number of units drawn from the bag during the current billing period

<Info>
The prepaid bag variant does not display a progress bar, since prepaid balances aren't tied to a fixed monthly allowance the way committed tiers are — the available units simply decrease as they're consumed, potentially across multiple billing periods.
</Info>

### How the Two Variants Differ

| | Committed Tier | Prepaid Bag |
|---|---|---|
| **Progress bar** | Yes, always emerald | Not shown |
| **Over-allowance handling** | Billable overage at tier price, applied next period | Not applicable — consumption simply reduces available balance |
| **Key figures** | Consumed / contracted units for the period | Available units and units consumed this period |
| **Tier or plan name** | Shown when configured | Not applicable |

<Steps>
<Step title="Balance Data Loads">
When consumption data is refreshed, the panel checks whether the response includes a `balance` object and, if so, which `kind` it reports
</Step>
<Step title="Correct Variant Renders">
The panel automatically renders the committed tier layout or the prepaid bag layout based on the `kind` field — no manual switching is needed
</Step>
<Step title="Figures Stay in Sync">
Both variants refresh alongside the rest of the consumption data whenever you change periods, apply a custom range, or trigger a manual refresh
</Step>
</Steps>

## Advanced Filtering System

### Predefined Period Filters

The panel automatically generates billing periods based on your account configuration:

- **Current billing period** (default selection)
- **Previous billing periods** (up to 8 historical periods)
- **Automatically calculated periods** based on your billing cycle start day

### Period Selector Dropdown

Instead of a simple inline list, period selection is handled through a compact dropdown control that keeps the filter panel tidy while still surfacing all available billing periods.

<Steps>
<Step title="Open Filter Section">
Click "Filter" to expand the filtering controls
</Step>

<Step title="Open the Period Dropdown">
Click the period selector button, which displays the currently selected period label and a chevron icon. Clicking it opens a scrollable list of all available periods
</Step>

<Step title="Choose a Period">
Select any period from the list. The chosen option is marked with a checkmark, the dropdown closes automatically, and consumption data refreshes for that period
</Step>
</Steps>

The dropdown behaves consistently across the panel:

- **Current selection highlighting**: The active period is visually highlighted with an emerald accent and checkmark
- **Click-outside to close**: Clicking anywhere outside the dropdown automatically closes it without changing the selection
- **Disabled while loading**: The dropdown button is disabled during data refresh to prevent conflicting requests
- **Re-selecting the current period**: Clicking the already-selected period does not trigger an unnecessary reload

<Steps>
<Step title="View Updated Data">
Data automatically refreshes when a new period is selected, including the minutes package card and balance block, when applicable
</Step>
</Steps>

### Custom Date Range Filtering

For flexible analysis beyond predefined periods:

<Steps>
<Step title="Set Start Date">
Use the "From" date picker to select your analysis start date
</Step>

<Step title="Set End Date">
Use the "To" date picker to define the end of your analysis period
</Step>

<Step title="Apply Custom Range">
Click "Apply" to load consumption data for your custom date range
</Step>
</Steps>

<Warning>
Custom date ranges must have a start date before or equal to the end date. The panel will show validation errors for invalid date combinations.
</Warning>

Once a custom range is applied, the period dropdown reflects the fact that a custom filter is active, and the panel keeps track of whether you're viewing a predefined period or a custom range so that manual refreshes reapply the correct filter type. The minutes package card and balance block, when applicable, recalculate against whatever range is currently active.

### Filter Collapse and Expansion

The filter section can be collapsed to save space while still providing quick access to filtering options:

<Steps>
<Step title="Toggle Filter Visibility">
Click the "Filter" header to expand or collapse the filtering controls
</Step>

<Step title="Access Quick Filters">
When collapsed, the section still shows the current filter status
</Step>

<Step title="Expand for Full Control">
Open the section to access all filtering options including the period dropdown and custom dates
</Step>
</Steps>

<Info>
Collapsing the filter section also automatically closes the period dropdown if it was open, keeping the interface predictable.
</Info>

### Filter States and Error Handling

The filtering system includes comprehensive validation:

- **Date validation**: Prevents invalid date combinations
- **Loading states**: Shows "Recalculating consumption..." during data refresh
- **Error recovery**: Displays helpful error messages and retry options
- **Auto-synchronization**: Keeps filter state, dropdown selection, and consumption data in sync

## Collapsed Mode: Rotating Message Ticker

When the panel is collapsed, instead of showing a static indicator, Billy displays a rotating ticker of short, contextual messages. This keeps key information visible even when you don't have the panel expanded.

<Info>
The ticker only runs while the panel is collapsed. Expanding the panel automatically stops the rotation, and collapsing it again resets the ticker to its first message before resuming.
</Info>

What the ticker can surface:

- **Total for the period**: The current total cost for the active billing period, giving an at-a-glance summary without opening the panel
- **Minutes package status**: A reminder of remaining minutes, or an over-allowance warning, whenever a legacy minutes package is configured on the account's billing profile
- **Balance status**: For rules-v2 accounts, a message reflecting either the committed tier's remaining/overage status or the prepaid bag's available units
- **Top consuming assistant**: The assistant responsible for the highest consumption in the current period, helping surface which assistant is driving costs at a glance
- **Billing period context**: Which period is currently being tracked
- **Historical highlights**: Once historical data has been loaded for admin views, relevant trend messages may also rotate through the ticker

<Info>
Not every message type appears for every account. The ticker only includes messages relevant to the account's configuration — for example, an account without a minutes package or a balance block simply skips those messages and rotates through the ones that do apply.
</Info>

### How the Ticker Works

<Steps>
<Step title="Panel Collapses">
As soon as you collapse the panel, the ticker starts from its first available message
</Step>
<Step title="Automatic Rotation">
Messages rotate automatically at a fixed interval, with a brief fade transition between each message for a smooth visual effect
</Step>
<Step title="Data-Aware Content">
The set of available messages is rebuilt whenever consumption data is refreshed or historical data is loaded, so the ticker always reflects your latest data — including the current period total, minutes package status, balance status, and top consuming assistant when applicable
</Step>
<Step title="Panel Expands">
Expanding the panel stops the rotation immediately; the ticker resumes from the beginning the next time you collapse the panel
</Step>
</Steps>

<Warning>
If consumption data fails to load or the panel cannot render (for example, no billing profile is configured), the ticker has no messages to display and remains empty until data loads successfully.
</Warning>

## Understanding Consumption Data

### Breakdown by Assistant

Each assistant entry shows:

- **Assistant name** and identification
- **Usage metrics** with proper unit labels (minutes, calls, etc.)
- **Unit pricing** and subtotal calculations
- **Billing type** information

### Cost Calculation Structure

The panel displays a transparent cost breakdown:

```
Subtotal (all assistant usage)
+ Minimum Applied (billing minimums)
- Correction Amount (adjustments/credits)
= Total Cost
```

<Info>
The minutes package card and the rules-v2 balance block are independent of this cost breakdown. They reflect contracted or prepaid unit usage only and do not themselves alter the subtotal, minimums, or corrections shown below them — except for committed tier overage, which is billed separately at the tier price in the following period.
</Info>

### Unit Display and Formatting

- **Automatic pluralization**: Units display correctly for singular/plural amounts
- **Localized formatting**: Numbers and currency display according to your locale
- **Consistent precision**: Monetary values show appropriate decimal places, and minutes package and balance figures use the same locale-aware number formatting
- **Unit-aware conversion**: Balance figures stored in seconds are automatically displayed as minutes for readability, while call-based balances display their raw call counts

## Data Refresh and States

### Manual Refresh

<Steps>
<Step title="Trigger Refresh">
Click the circular arrow refresh icon in the panel header
</Step>
<Step title="Monitor Progress">
The icon shows a spinning animation during data loading
</Step>
<Step title="Handle Errors">
If refresh fails, the status indicator changes to amber and error messages appear
</Step>
</Steps>

The refresh button intelligently reapplies whichever filter is currently active:

- If a **custom date range** is active and both dates are set, the refresh re-applies that exact range
- If a **predefined period** is selected, the refresh reloads data for that same period
- If neither is set, it falls back to loading the default current-period consumption

This means you never lose your place when refreshing — the panel always returns data consistent with what you were already viewing, and the minutes package card and balance block (when applicable) update their figures accordingly.

### Smart Refresh Logic

The refresh system intelligently handles different scenarios:

- **Period filters**: Refreshes data for the currently selected period
- **Custom ranges**: Re-applies custom date filters
- **Default mode**: Falls back to standard consumption loading
- **State preservation**: Maintains current filter selections, dropdown state, and (when applicable) the historical chart's expanded/collapsed state

### Loading States

The panel provides clear feedback during operations:

- **"Recalculating consumption..."**: Data is being refreshed
- **"Loading billing history..."**: Historical chart data is loading
- **Disabled controls**: Prevent multiple simultaneous requests, including the period dropdown button

### Error Recovery

When errors occur, the panel:
- Changes status indicator to amber
- Displays clear error messages
- Allows retry through manual refresh
- Maintains last successful data when possible

<Warning>
If consumption data fails to load, neither the minutes package card nor the rules-v2 balance block are rendered — they do not display a stale or partial state. They reappear automatically once a successful refresh returns their respective data again.
</Warning>

## Best Practices

### Regular Monitoring
- **Check consumption frequently** to stay within budget limits
- **Watch the minutes package bar** to anticipate reaching your contracted allowance before it turns red
- **Watch the balance block** for rules-v2 accounts to track committed tier usage or prepaid bag depletion
- **Use period comparisons** to identify usage trends
- **Monitor assistant performance** to optimize resource allocation

### Effective Filtering
- **Start with the period dropdown** for standard analysis
- **Use custom ranges** for specific investigation periods
- **Collapse filters** when not actively adjusting to save space
- **Combine filters** with manual refresh for most current data

### Administrative Usage
- **Review historical charts** for long-term planning
- **Monitor client consumption patterns** for resource allocation
- **Use trend analysis** for budget forecasting
- **Toggle chart visibility** to optimize screen space, relying on cached data for quick re-opening

### Collapsed Mode Usage
- **Keep the panel collapsed** during regular work to let the ticker surface key updates passively
- **Glance at rotating messages** for a quick pulse on the period total, minutes package or balance status, and top consuming assistant without expanding the panel
- **Expand only when you need details**, such as adjusting filters or reviewing historical charts

### Managing a Minutes Package
- **Treat the emerald bar as a planning tool**: use the remaining-minutes footer message to anticipate when the allowance will run out
- **Treat red as an alert, not a block**: when the bar turns red, review usage drivers (which assistants, which periods) rather than assuming calls have stopped
- **Cross-check with your Billy profile**: if the contracted figure looks wrong, verify the configured allowance directly on the billing profile rather than only in the panel

### Managing a Rules-v2 Balance
- **Treat committed tier overage as billable, not urgent**: it will simply be invoiced at the tier price next period, so no immediate action is required unless the volume looks unexpected
- **Monitor prepaid bag depletion proactively**: since there's no automatic renewal, keep an eye on available units to plan the next top-up before the balance runs out
- **Use the tier name to confirm the active contract**: if you expect a different tier price or volume, verify the tier name shown against what's configured on the account

### Performance Optimization
- **Keep the panel collapsed** when not actively monitoring
- **Collapse filter sections** when not in use
- **Refresh manually** when you need the most current data
- **Use appropriate filter periods** to avoid loading excessive data

<Info>
The panel automatically saves your collapsed/expanded preference and filter settings, restoring them when you return to the dashboard.
</Info>
