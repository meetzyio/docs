# Detalles de Llamada

Cada llamada genera datos detallados que te ayudan a entender qué sucedió durante la conversación. El modal de Detalles de Llamada proporciona acceso a toda la información capturada.

## Abrir Detalles de Llamada

Haz clic en cualquier fila de la tabla de Historial de Llamadas, o haz clic en el botón **View** para abrir el modal de detalles.

## Diseño del Modal

El modal de Detalles está organizado en un layout de tres columnas:

| Panel | Contenido |
|-------|-----------|
| ⬅️ Izquierda | Parámetros de Entrada (JSON) |
| 📊 Centro | Información de la Llamada |
| ➡️ Derecha | Respuesta de Salida (JSON) |

## Parámetros de Entrada

El panel izquierdo muestra el JSON de entrada enviado para iniciar la llamada:

```json
{
  "phone": "+1234567890",
  "customer_name": "Juan García",
  "appointment_date": "2024-02-15",
  "custom_fields": {
    "order_id": "ORD-12345"
  }
}
```

### Funcionalidades

- **Botón Copiar** - Copia todo el JSON al portapapeles
- **Resaltado de Sintaxis** - JSON con colores para legibilidad
- **Expandible** - Scroll para payloads grandes

## Información de la Llamada

El panel central muestra metadatos clave:

| Campo | Descripción |
|-------|-------------|
| Call ID | Identificador único (monoespaciado, copiable) |
| Status | Estado actual con badge de color |
| Success | Indicador ✓ Sí o ✗ No |
| Playbook | Nombre del agente que manejó la llamada |
| Duration | Duración en formato legible |
| From | Número de teléfono origen |
| To | Número de teléfono destino |
| Email | Email del contacto (si se proporcionó) |
| Created Time | Timestamp de inicio de la llamada |
| Tags | Etiquetas aplicadas a esta llamada |

### Badges de Estado

| Estado | Color | Descripción |
|--------|-------|-------------|
| completed | 🟢 Verde | Llamada terminada normalmente |
| in-progress | 🔵 Azul | Llamada actualmente activa |
| failed | 🔴 Rojo | Llamada con error |
| transferred | 🟣 Morado | Llamada transferida |
| no-answer | ⚪ Gris | El destinatario no contestó |

## Bloque LLM

<Info>
Este bloque solo aparece si la llamada tiene datos de uso de modelos LLM registrados. Las llamadas anteriores al 29 de julio de 2026 pueden mostrar un único modelo mediante un campo de compatibilidad.
</Info>

El panel central incluye una sección **LLM** que muestra qué modelo (o modelos) de lenguaje procesó la conversación. Meetzy utiliza un sistema de cascada de proveedores (por ejemplo, ElevenLabs) que puede degradar automáticamente a un modelo alternativo si el modelo principal no está disponible o presenta latencia elevada.

### Qué muestra

| Elemento | Descripción |
|----------|-------------|
| Modelos usados | Lista de los modelos distintos utilizados durante la llamada, en orden de aparición |
| Indicador de degradación | Se activa cuando se detecta más de un modelo distinto en la misma llamada |
| Detalle por turno | Desglose opcional que muestra qué modelo respondió en cada turno de la conversación |

### Indicador de Degradación

<Warning>
Cuando una llamada usa más de un modelo LLM, se considera que hubo una **degradación del cascade**: el modelo principal no pudo atender la solicitud en algún punto y el sistema recurrió a un modelo alternativo para mantener la llamada en curso.
</Warning>

Este indicador te ayuda a identificar rápidamente llamadas que pudieron verse afectadas por cambios de modelo, útil para:

- Detectar problemas de disponibilidad con un proveedor específico
- Correlacionar degradaciones con caídas de calidad en la conversación
- Priorizar la revisión manual de llamadas con cascade activo

### Detalle por Turno

Por defecto, el detalle por turno aparece **plegado**. Al expandirlo, verás una tabla con:

| Campo | Descripción |
|-------|-------------|
| Turno | Marca de tiempo (en segundos) dentro de la llamada |
| Modelo(s) | Modelo o combinación de modelos usados en ese turno |
| Tokens de salida | Cantidad de tokens generados por el modelo en ese turno |

<Steps>
<Step title="Localiza el bloque LLM">
En el panel central del modal de detalles, busca la sección **LLM** debajo de la información básica de la llamada.
</Step>
<Step title="Revisa los modelos usados">
Verás la lista de modelos distintos detectados en la llamada. Si hay más de uno, aparecerá el indicador de degradación.
</Step>
<Step title="Expande el detalle por turno">
Haz clic para desplegar la tabla de turnos y ver exactamente en qué momento ocurrió el cambio de modelo.
</Step>
</Steps>

<Info>
Esta información es especialmente útil junto con el botón **"Analyze with AI"**: puedes pedirle al Copilot que correlacione una degradación de modelo con caídas de sentimiento o errores en la conversación.
</Info>

## Respuesta de Salida

El panel derecho muestra el JSON de salida con todos los datos capturados:

```json
{
  "transcription": "Agente: Hola, soy Sara de...",
  "summary": "El cliente confirmó la cita para...",
  "sentiment": "positive",
  "output_params": {
    "appointment_confirmed": true,
    "preferred_time": "morning",
    "callback_requested": false
  },
  "evaluations": {
    "successful_greeting": true,
    "collected_requirements": true
  }
}
```

### Contenido de Salida

<AccordionGroup>
  <Accordion title="Transcripción">
    Transcripción completa de la conversación entre el agente y el llamante, con etiquetas de hablante.
  </Accordion>
  <Accordion title="Resumen">
    Resumen generado por IA de los puntos clave y resultados de la llamada.
  </Accordion>
  <Accordion title="Parámetros de Salida">
    Datos estructurados extraídos de la conversación según tu configuración de Output Settings.
  </Accordion>
  <Accordion title="Evaluaciones">
    Resultados de evaluaciones automáticas definidas en la configuración del agente.
  </Accordion>
  <Accordion title="Tool Calls">
    Si el agente invocó herramientas o webhooks, sus peticiones y respuestas se incluyen.
  </Accordion>
</AccordionGroup>

## Navegación al Copilot

<Info>
Desde los detalles de cualquier llamada, puedes navegar directamente al Copilot de IA con el contexto de la conversación precargado.
</Info>

### Acceso Contextual

En el panel central de información de la llamada, encontrarás un botón **"Analyze with AI"** que te permite:

<Steps>
<Step title="Navegación Contextual">
Haz clic en **"Analyze with AI"** para abrir el Copilot con el contexto de la llamada
</Step>
<Step title="Contexto Precargado">
El Copilot se abrirá automáticamente con referencia `@call:<id>` que incluye toda la transcripción
</Step>
<Step title="Análisis Inteligente">
Realiza consultas como "Analiza el sentimiento de esta llamada" o "Genera un resumen ejecutivo"
</Step>
</Steps>

### Casos de Uso del Copilot

<CardGroup cols={2}>
  <Card title="Análisis de Sentimiento" icon="heart">
    Evalúa el tono emocional de la conversación y la satisfacción del cliente
  </Card>
  <Card title="Extracción de Insights" icon="lightbulb">
    Identifica patrones, objeciones comunes y oportunidades de mejora
  </Card>
  <Card title="Optimización de Prompts" icon="wand-magic-sparkles">
    Mejora los prompts del agente basándose en conversaciones reales
  </Card>
  <Card title="Generación de Reportes" icon="chart-bar">
    Crea resúmenes ejecutivos y análisis detallados de rendimiento
  </Card>
</CardGroup>

### Flujo de Trabajo Integrado

El sistema proporciona una experiencia fluida entre el análisis de llamadas y la optimización de agentes:

1. **Revisar Llamada** - Examina transcripción y métricas en el modal de detalles
2. **Analizar con IA** - Un clic te lleva al Copilot con contexto completo
3. **Optimizar Agente** - Aplica mejoras directamente al agente desde el Copilot
4. **Validar Cambios** - Regresa al historial para verificar el impacto

## Información de Webhook

Si tu agente tiene un webhook configurado, la parte inferior del panel derecho muestra:

| Campo | Valor |
|-------|-------|
| Method | POST, GET, etc. |
| URL | Endpoint del webhook |
| Auth | Header de autorización (oculto) |

<Info>
La sección de webhook solo aparece si se configuró y ejecutó un webhook para esta llamada.
</Info>

## Reproducción de Grabación

Si la grabación de llamadas está habilitada:

1. Aparece un reproductor de audio en la parte superior del modal
2. Controles incluyen play/pause, seek y volumen
3. Opción de descarga disponible para acceso offline

<Warning>
Las grabaciones de llamadas se almacenan por tiempo limitado según tu plan. Descarga grabaciones importantes para almacenamiento permanente.
</Warning>

## Copiar Datos

### Botones de Copiar

- **Copy Input** - Copia todo el JSON de entrada
- **Copy Output** - Copia todo el JSON de salida
- **Copy Call ID** - Copia solo el identificador de llamada

### Feedback

Cuando copias datos:
- El botón cambia a "Copied!" con un checkmark
- Vuelve a la normalidad después de 2 segundos
