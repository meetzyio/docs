## Overview

The **Agents** page has been fully redesigned around a **master-detail layout**: a compact agent list on the left and a rich detail panel on the right, so you can browse, inspect, and act on any agent without leaving the page.

<Info>
  This redesign replaces the classic Agents page. A **"Switch back to the classic view"** banner remains available at the top of the screen while both experiences coexist.
</Info>

<Tabs>
  <Tab title="Agents List (left)">
    A scrollable list of agents with search, company filter, and an **Archived agents** visibility toggle. Selecting an agent loads its details on the right without a full page reload. Each row also surfaces a phone health indicator and a latency mini-chart at a glance.
  </Tab>
  <Tab title="Detail Panel (right)">
    A tabbed panel — **Overview**, **Calls**, and **Settings** — showing everything about the selected agent: performance metrics, latency history, call log, and configuration.
  </Tab>
</Tabs>

## Agent List and Filters

### Search and Company Filter

The filters bar above the list lets admins and multi-company users narrow down the agent list quickly:

| Filter | Description |
|--------|-------------|
| **Search** | Matches agent name, company, or agent ID in real time |
| **Company** | Dropdown with a built-in search box to filter agents by organization; defaults to **"All companies"** |
| **Archived agents** | Toggle switch to show or hide archived agents in the list (hidden by default) |
| **Phone health** | Toggle switch to show only agents whose numbers currently have spam/deliverability issues |
| **Clear filters** | Appears only when at least one filter is active, resetting search, company, archived visibility, and the phone health filter |

<Tip>
  The company filter dropdown includes its own search box, making it easy to jump straight to a specific organization when you manage dozens of companies.
</Tip>

### Selecting an Agent

Click any row in the list to open it in the detail panel. The selected row is highlighted with a colored left border, and archived agents display a small **Archived** badge next to their name.

### Phone Health Indicator and Latency Mini-Chart

Every row in the agent list now includes two at-a-glance signals, so you no longer need to open an agent to spot a problem:

- **Phone health beacon**: a small colored dot next to the agent's phone number reflecting the spam/deliverability status of its assigned numbers (green = healthy, red = spam issues detected, gray = status unknown or still loading). Click it to jump straight into the [Phone Health](/agents/phone-numbers) report for that agent.
- **Latency sparkline**: a compact 14-day mini-chart of average AI response latency, rendered inline in the row. It uses the same underlying data as the Overview tab's latency history chart, letting you compare agents' recent performance without opening each one individually.

<Info>
  Latency history and phone health data for all visible agents are fetched in the background right after the list loads, so the initial render stays fast and the sparklines/beacons populate a moment later.
</Info>

## Agent Detail Panel

Once an agent is selected, the detail panel on the right organizes all information into three tabs:

<Tabs>
  <Tab title="Overview">
    **Performance dashboard** for the agent, including:
    - **Summary cards**: total calls, average call duration, and average AI latency (with a trend arrow comparing recent vs. previous performance, plus a P90 latency reading)
    - **Latency history chart**: a 14-day time series of average AI response latency, helping you spot regressions or improvements over time
    - **Call volume chart**: a 30-day time series of daily call counts
    - **Phone health**: a clickable card linking to the spam/deliverability report for the agent's assigned numbers
    - **Quick actions**: **Editor** (Advanced agents only), **Trends** (Advanced agents only), **Clone**, and **Archive**
  </Tab>
  <Tab title="Calls">
    A sortable table of the agent's calls from the last 90 days, including date, origin number, status, duration, and latency. Admin users additionally see quick links per call. Recordings can be played directly from this tab using the same player used across the Calls section.
  </Tab>
  <Tab title="Settings">
    The full configuration form for standard (non-Advanced) agents — the same settings previously available on the classic page, including save/discard change detection and an editing timeout safeguard. Advanced agents don't show this tab since their configuration is managed from the [Advanced Editor](/agents/advanced-editor).
  </Tab>
</Tabs>

<Info>
  The **Avg AI latency** trend arrow compares the average of the most recent half of the visible days against the earlier half — an upward red arrow means latency is increasing, a downward green arrow means it's improving. It only appears once enough daily data points are available.
</Info>

### Summary Cards

The three cards at the top of the Overview tab give you an instant read on agent health:

| Card | What it shows |
|------|---------------|
| **Total calls** | Total number of calls handled by the agent |
| **Avg duration** | Average call length, formatted as minutes:seconds |
| **Avg AI latency** | Average AI response latency in milliseconds, its trend arrow, and the P90 latency value underneath |

### Latency History and Call Volume Charts

Below the summary cards, two charts plot the agent's daily behavior over time:

- **Latency history (14 days)**: average AI latency per day, plotted chronologically to make regressions easy to spot.
- **Call volume (30 days)**: number of calls handled per day, useful for spotting usage spikes or drop-offs.

Both charts share the same rendering component and gracefully show an empty state message when there isn't enough data yet.

### Phone Health Shortcut

The **Phone health** card sits below the charts and links directly to the spam/deliverability report for the numbers assigned to the selected agent — the same report reachable from the row-level beacon in the agent list.

### Quick Actions

At the bottom of the Overview tab, a row of quick action buttons lets you jump straight into common workflows without leaving the detail panel:

- **Editor** — opens the [Advanced Editor](/agents/advanced-editor) in a new tab (Advanced agents only)
- **Trends** — opens the evaluation trends view for this agent in a new tab (Advanced agents only)
- **Clone** — launches the clone assistant described below
- **Archive** — launches the archive confirmation flow described below

## Clone Agents

Agent cloning now uses a guided **two-step assistant** instead of a single form, making it clear exactly what will be duplicated before anything is created.

<Steps>
  <Step title="Step 1 — Configure the Clone">
    Open **Clone** from the agent's Overview tab (or from the row's quick actions) to fill in the base configuration:
    - **Agent Name**: defaults to `<Original Name> (Copy)`, fully editable
    - **Target Company**: shown only to admin users on the Meetzy domain with access to multiple companies; regular users automatically clone into their own company
    - **Phone Number**: select an available number from the same Twilio account as the original agent — the list loads automatically once a company is chosen
    - **Number Usage**: choose whether the assigned number is used for **Outbound & Inbound**, **Outbound only**, or **Inbound only**
    - **Agent Tools**: choose between **Duplicate tools** (independent copies, safe to edit separately) or **Reuse existing tools** (both agents share the same tools, and edits to one affect the other)
  </Step>
  <Step title="Step 2 — Review and Confirm">
    Clicking **Continue** moves to a summary screen listing the target company, the phone number and its usage mode, and the tools strategy in plain language before you confirm. Use **Back** to return and adjust any setting.
  </Step>
  <Step title="Cloning in Progress">
    Confirming triggers the clone request; the button switches to a disabled **"Cloning..."** state to prevent duplicate submissions. On success, the new agent appears in the list; on failure, an inline error message explains what went wrong so you can retry without losing your inputs.
  </Step>
</Steps>

<Warning>
  If the original agent's Twilio account has no available numbers, the modal shows a warning explaining that a free number from the **same account as the original agent** is required — release a number or purchase a new one before cloning.
</Warning>

<Note>
  The list of tools on the original agent is loaded and shown in the modal so you know exactly what will be duplicated or shared before confirming.
</Note>

## Archive Agents

<Info>
  Archiving is the recommended way to retire an agent you no longer need while keeping its configuration, call history, and analytics intact for future reference.
</Info>

Archiving deactivates an agent without deleting its data. The **Archive Agent** modal, available from the Overview tab's quick actions, guides you through the process:

<Steps>
  <Step title="Review the Confirmation">
    The modal explains that this will hide the agent from the agents list without deleting any of its data.
  </Step>
  <Step title="Choose Phone Number Handling">
    A dedicated checkbox lets you **"Release its phone number for other agents"**:
    - **Checked**: resets the Twilio configuration and frees the number so it can be assigned to another agent
    - **Unchecked (default)**: the number stays reserved with this agent
  </Step>
  <Step title="Confirm">
    Click **Archive** to proceed. The button shows an **"Archiving..."** loading state while the request completes. Any error is displayed inline in the modal so you can retry safely.
  </Step>
</Steps>

<Warning>
  Releasing the phone number is **irreversible** — once released, the number may be reassigned to a different agent or company. Leave the checkbox disabled if you plan to reactivate this agent later with the same number.
</Warning>

### Restoring an Archived Agent

Toggle **Archived agents** to **Shown** in the filters bar to locate an archived agent, select it, and restore it from its detail panel. If its phone number was released during archiving, assign a new one from the [Phone Numbers](/agents/phone-numbers) section before it can resume handling calls.

## Swap Phone Number

The **Swap Phone Number** modal lets you replace an agent's current number with a new one from the same Twilio account — useful when a number develops deliverability issues or needs to be freed up.

<Steps>
  <Step title="Open the Swap Modal">
    From the "Call" side panel next to any phone number, or from the agent's Settings, click the swap icon next to the number you want to replace.
  </Step>
  <Step title="Review the Swap">
    The modal displays the **current number** (marked for release) and automatically loads the **next available number** from the same Twilio account to assign in its place.
  </Step>
  <Step title="Confirm">
    Click **Confirm Swap** to apply the change. The button enters a **"Swapping..."** state while the request is processed against both the database and Twilio. If no available numbers are found, an inline message tells you so, including the Twilio account label.
  </Step>
</Steps>

<Warning>
  A swap updates both your database and Twilio configuration immediately, and the old number is marked for release. This action cannot be undone from the modal.
</Warning>

## Custom Call Form Fields

Every agent that accepts outbound test/init calls has a configurable form. The **Configure Form Fields** editor lets you manage the custom fields shown in that form, beyond the built-in system fields.

<Info>
  System fields — **phone**, **voice**, and **language** — are always required and cannot be edited or removed from this editor.
</Info>

<Steps>
  <Step title="Open the Field Editor">
    Click **Edit Form** in the "Call" panel of any agent to open the **Configure Form Fields** modal.
  </Step>
  <Step title="Add or Edit Fields">
    For each custom field, configure:
    - **Field Label**: the text shown to users filling out the form
    - **Field Type**: Text, Email, Number, Phone, or Dropdown
    - **Parameter ID**: the identifier referenced in your agent's prompt as `{{id}}` — auto-generated from the label but fully editable
    - **Placeholder Text**: optional hint text shown inside the input
    - **Required field**: whether the field must be filled before a call can be started
  </Step>
  <Step title="Remove Fields">
    Click the trash icon on any field card to delete it (with a confirmation prompt).
  </Step>
  <Step title="Save">
    Click **Save** to persist the field configuration. Parameter IDs are validated for uniqueness and checked against system field names before saving; any conflict is reported inline so you can fix it without losing your changes.
  </Step>
</Steps>

<Tip>
  Custom Parameter IDs are automatically slugified from the field label (lowercase, no accents, underscores instead of spaces) unless you manually override them.
</Tip>

## Test Calling from the "Call" Panel

Each agent row includes a **Call** side panel with everything needed to place a quick test call — inbound or outbound — without leaving the Agents page.

<Tabs>
  <Tab title="Inbound Testing">
    The panel lists the agent's assigned phone number(s) as clickable `tel:` links, plus a one-click **copy without country code** button for each number. If the agent only has verified caller IDs (no inbound number), a note clarifies it only supports outbound calls.
  </Tab>
  <Tab title="Outbound Testing">
    A dynamic form built from the agent's configured fields (including any custom fields added via the field editor), plus:
    - **Country prefix selector**: choose from a long list of country codes (with flags) next to the phone input — your last choice is remembered for next time via local storage
    - **Agent Version selector**: for Advanced agents only, choose a specific saved version to test against, or leave it blank to use the production version
    - **Edit Form** shortcut to open the custom fields editor directly from the panel
  </Tab>
</Tabs>

<Warning>
  Test calls consume billable minutes from your plan. Monitor usage in the billing dashboard.
</Warning>

## Permissions and Access Control

<Tabs>
  <Tab title="Admin Users">
    - Full access to clone, archive, restore, and swap phone numbers on any agent
    - Company filter available in both the agent list and the clone modal's target company selector
    - Cross-company agent management
  </Tab>
  <Tab title="Advanced Editor Users">
    - Create and edit Advanced agents via the [Advanced Editor](/agents/advanced-editor)
    - Clone, archive, and manage phone numbers for their own agents
    - Access to Settings tab for standard agents
  </Tab>
  <Tab title="Standard Users">
    - View assigned agents and their Overview/Calls tabs
    - Place test calls using the Call panel
    - Limited or no access to Archive, Clone, and Settings depending on role
  </Tab>
</Tabs>
