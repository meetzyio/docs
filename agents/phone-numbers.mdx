## Phone Numbers in Meetzy

Each Meetzy agent needs at least one phone number to:

- **Receive inbound calls**
- **Make outbound calls**
- **Identify itself** (caller ID)

<Info>
  Phone numbers are exclusive resources. Each number can only be assigned to one agent at a time.
</Info>

## Phone Number Types

Meetzy supports two types of phone numbers for your agents:

### Twilio Phone Numbers
Standard phone numbers managed through your Twilio account:
- Automatically provisioned and configured
- Support both inbound and outbound calls
- Can be swapped and reassigned automatically
- Managed through Meetzy's interface

### Verified Caller IDs
Client-owned phone numbers verified for outbound calling:
- Numbers you already own and want to use as caller ID
- Must be verified through Twilio's verification process
- Appear with a special verification badge in the interface
- Cannot be swapped automatically (manual process required)

<Warning>
  Caller IDs are for outbound calling only and cannot be automatically rotated like Twilio numbers. They require manual management for spam protection.
</Warning>

## Visual Identification

In the Meetzy interface, you can distinguish between phone number types:

| Type | Visual Indicator | Description |
|------|------------------|-------------|
| **Twilio Number** | Standard format with swap controls | Fully managed by Meetzy |
| **Verified Caller ID** | 🔒 Lock icon with verification badge | Client-owned verified number |

<Info>
  Verified Caller IDs show verification status badges (pending, verified, disabled) to help you track their state.
</Info>

## Outbound Numbers Panel

Every agent in the Advanced Editor now includes an **Outbound numbers** panel in the left sidebar. This panel shows, in one place, exactly which numbers the agent calls from and lets you manage them without leaving the editor.

### The Rotation List

The panel displays the numbers currently **in rotation** for the agent — the ones it actually uses to place outbound calls:

- Each number shows its **E.164 format** and a **type badge** describing what kind of number it is.
- If the number is a purchased line (not a caller ID), it also shows a **"Line"** tag.
- Numbers marked **Temporary use** come from Meetzy's shared 400 pool and may be rotated out automatically.
- If a number is also used by other agents in the same account, you'll see a note like *"Also used by 2 other agents"*.
- A single status banner at the top summarizes the agent's calling behavior in plain language, for example:
  - 🟢 *"Calls only from 400 numbers"*
  - ⚪ *"Calls from the numbers below. When you add a 400 number, it calls only from 400 numbers."*
  - 🔴 *"This agent can't make calls yet. Add at least one 400 number."*
  - 🟡 *"Meetzy set this agent up for customer service calls, so it calls from landline numbers. Contact us to change it."*

<Info>
  You don't choose the call type manually anymore — it's inferred from the list. As soon as the agent has at least one 400 number in rotation, it automatically switches to calling only from 400 numbers.
</Info>

#### Number Type Badges

Every number in the panel is labeled with its type, so you can tell at a glance what you're working with:

| Badge | Meaning |
|-------|---------|
| **400** | Landline-style number from Meetzy's compliant pool, used for commercial campaigns |
| **Mobile** | Mobile phone number |
| **800/900** | Toll-free or premium-rate number |
| **Landline** | Standard geographic landline number |
| **Foreign** | Number from a country different from the agent's main market |

<Info>
  400 numbers are highlighted with a distinct green badge, since adding one changes the agent's calling behavior to "only 400 numbers".
</Info>

### Adding Numbers from Your Account

The **Add numbers** button opens a picker with the verified Caller IDs available in the agent's account — including numbers already in use by other agents:

<Steps>
  <Step title="Click Add numbers">
    Open the picker from the Outbound numbers panel.
  </Step>
  <Step title="Browse available numbers">
    By default, the list hides numbers already assigned to other agents to keep things simple. If you need one of those, toggle **Show numbers already in use** to reveal them, each marked with a note like *"Already used by 2 of your agents"*.
  </Step>
  <Step title="Select multiple numbers">
    Check as many numbers as you need. Numbers that can't be added yet appear in a separate section with the reason why (for example, pending verification).
  </Step>
  <Step title="Use Select all 400 as a shortcut">
    If you just want to load up on compliant 400 numbers, click **Select all 400** to check every available 400 number in one click (numbers already shared with other agents are excluded from this shortcut to avoid accidental overlaps).
  </Step>
  <Step title="Confirm">
    The selected numbers are added to the rotation immediately. The panel reports how many were added and refreshes the status banner — if this introduces the agent's first 400 number, you'll see a note that the agent now calls only from 400 numbers.
  </Step>
</Steps>

<Info>
  Only Caller IDs appear in this picker. Purchased lines (Twilio numbers) are managed from the agent's phone number configuration, not from this panel.
</Info>

### Copying Numbers to Other Agents

Use **Copy to other agents** to quickly replicate this agent's numbers across your account:

<Steps>
  <Step title="Click Copy to other agents">
    This opens a list of other agents in the same account, each showing their current number count and whether they already have a 400 number.
  </Step>
  <Step title="Select target agents">
    Choose one or more agents to receive this agent's numbers.
  </Step>
  <Step title="Confirm copy">
    The system attempts to add the numbers to each selected agent and reports the result per agent.
  </Step>
</Steps>

Each target agent gets one of these outcomes:

| Result | Meaning |
|--------|---------|
| **Added** | The numbers were successfully added to that agent's rotation |
| **No changes needed** | The agent already had all of those numbers |
| **Not allowed** | The copy was blocked for that agent (for example, a locked customer-service agent that can't receive 400 numbers) |
| **Error** | Something went wrong adding one or more numbers; details are shown per number |

<Warning>
  Copying numbers may change the calling behavior of the target agent if it introduces a 400 number for the first time — the target agent will then also call only from 400 numbers.
</Warning>

### Verifying Your Own Number

If you want to use a number you already own (such as your office line) as a caller ID, use **Add your own number**. Meetzy verifies ownership with a short phone call:

<Steps>
  <Step title="Open the verification form">
    Click **Add your own number** in the Outbound numbers panel.
  </Step>
  <Step title="Enter the phone number">
    Type the number you own, in international format (e.g. `+34910000000`), and optionally give it a friendly name (e.g. "Main office") so it's easy to recognize later in the rotation list.
  </Step>
  <Step title="Request the call">
    Click **Call me with the code**. Meetzy places a call to that number.
  </Step>
  <Step title="Answer and enter the code">
    Answer the call and type the **6-digit code** shown on screen using your keypad.
  </Step>
  <Step title="Confirm verification">
    Once the code is entered correctly, the number is verified and, if possible, assigned to the agent automatically.
  </Step>
</Steps>

<Warning>
  400 numbers can't receive this verification call. If you need a 400 number added, open a request to the Meetzy team instead of using self-verification.
</Warning>

<Info>
  If the call fails or you miss it, simply click **Call me with the code** again to request a new call and a new code.
</Info>

<Info>
  If the verified number can't be assigned to this specific agent (for example, due to account rules), it still becomes available for your other agents and the panel will explain why.
</Info>

### Account-Wide "Only 400 Numbers" Toggle

The Meetzy team has access to an account-level switch called **only 400 numbers**. When enabled for an account:

- All agents in that account are forced to call only from 400 numbers, regardless of their individual rotation.
- This is reflected in the status banner and overrides the per-agent behavior.
- It's intended for accounts that require strict compliance with landline-only outbound calling policies.

<Info>
  This toggle is managed internally by the Meetzy team and is not available for self-service in the client dashboard. If your account needs this setting, contact Meetzy support.
</Info>

## Multi-Subaccount Phone Number Management

Meetzy now supports managing phone numbers across multiple Twilio subaccounts with enhanced assignment states and improved management features.

### Assignment States

Phone numbers can have three distinct assignment states:

| State | Description | Visual Indicator |
|-------|-------------|------------------|
| **Assigned** | Fully assigned to an agent and active | 🟢 Green badge |
| **Partial** | Partially assigned or pending configuration | 🟡 Yellow badge |
| **Unassigned** | Available for assignment | ⚪ Gray badge |

### Subaccount Credentials Management

Each Twilio subaccount can have its own set of credentials configured independently:

<Tabs>
  <Tab title="Main Account">
    Your primary Twilio account with full management capabilities
  </Tab>
  <Tab title="Configured Subaccounts">
    Subaccounts with proper credentials - full management available
  </Tab>
  <Tab title="Unconfigured Subaccounts">
    Subaccounts without credentials - view-only access
  </Tab>
</Tabs>

<Warning>
  To fully manage phone numbers in a subaccount, you need to configure the subaccount credentials in your settings.
</Warning>

## Twilio Subaccount Navigation

The phone numbers interface includes a tabbed navigation system to manage numbers across different Twilio subaccounts:

### How to Navigate Between Subaccounts

<Steps>
  <Step title="View Available Subaccounts">
    Look for the tab interface at the top of the phone numbers page.
  </Step>
  <Step title="Select Subaccount">
    Click on any tab to switch to that subaccount's phone numbers.
  </Step>
  <Step title="Wait for Loading">
    The system will load numbers for the selected subaccount automatically.
  </Step>
  <Step title="Check Credential Status">
    Look for the credential status badge on each subaccount tab.
  </Step>
</Steps>

<Info>
  Phone numbers are cached per subaccount to improve performance when switching between tabs.
</Info>

| **Assigned** | Shows only numbers assigned to agents | Review active assignments |

## Direct Agent Assignment System

The new assignment system allows you to directly assign phone numbers to agents with improved feedback:

<Steps>
  <Step title="Locate Available Number">
    Find an unassigned number in the list.
  </Step>
  <Step title="Click Assign">
    Click the "Assign" button next to the phone number.
  </Step>
  <Step title="Select Agent">
    Choose an agent from the dropdown list of available agents.
  </Step>
  <Step title="Confirm Assignment">
    Click confirm to complete the assignment with automatic state updates.
  </Step>
</Steps>

### Assignment Process

When you assign a number:
1. The number's status changes to **assigned**
2. The agent's configuration is updated
3. The cache is refreshed for real-time updates
4. Assignment status is reflected across all relevant interfaces

<Warning>
  Once assigned directly, the number will become unavailable for other agents until reassigned, reset, or returned.
</Warning>

## Advanced Number Management Operations

### Reset Numbers

The reset function allows you to clear a number's configuration while keeping it in your account:

<Steps>
  <Step title="Select Number to Reset">
    Find the phone number you want to reset.
  </Step>
  <Step title="Click Reset">
    Use the reset option in the number's actions menu.
  </Step>
  <Step title="Confirm Reset">
    Confirm the reset operation - this will clear webhooks and assignments.
  </Step>
  <Step title="Verify Status">
    The number will return to **unassigned** status and be available for new assignments.
  </Step>
</Steps>

### Return Numbers

The return function removes numbers from your account completely:

<Steps>
  <Step title="Select Number to Return">
    Find the phone number you want to return to Twilio's pool.
  </Step>
  <Step title="Click Return">
    Use the return option in the number's actions menu.
  </Step>
  <Step title="Confirm Return">
    Confirm the return operation - this action cannot be undone.
  </Step>
  <Step title="Number Released">
    The number is returned to Twilio and removed from your account.
  </Step>
</Steps>

<Warning>
  Returned numbers cannot be recovered. They may be assigned to other customers.
</Warning>

## Assign a Number When Creating an Agent

When creating a new agent in the Advanced Editor:

1. Go to the **Settings** section (Cog icon)
2. Find the **Phone Number** field
3. Select an available number from the dropdown

### If No Numbers Are Available

If the dropdown is empty, you'll see a message:

```
No available phone numbers for the selected account.
All numbers are assigned or configured.
```

**Options:**
- Release a number from another agent
- Reset unused numbers
- Request new numbers via the "Request more numbers" link

## View Assigned Numbers

Once assigned, the number appears in read-only mode:

```
Phone Number: +1 555 123 4567 (Sales Team) 🔒
Phone number assigned to this agent
```

<Warning>
  The phone number cannot be changed directly once assigned. To change it, use the Swap function from Phone Health.
</Warning>

## Caller ID Management

Verified Caller IDs provide additional flexibility for outbound calling with your own phone numbers.

### Adding a Caller ID

<Steps>
  <Step title="Navigate to Agent Settings">
    Open the agent configuration in the Advanced Editor.
  </Step>
  <Step title="Add Caller ID">
    In the Caller IDs section, enter your phone number.
  </Step>
  <Step title="Start Verification">
    Twilio will initiate the verification process.
  </Step>
  <Step title="Complete Verification">
    Follow the verification steps provided by Twilio.
  </Step>
</Steps>

<Info>
  You can also start this same verification flow directly from the **Outbound numbers** panel using **Add your own number**. See [Verifying Your Own Number](#verifying-your-own-number) above for the step-by-step call-and-code process.
</Info>

### Caller ID Limitations

<Warning>
  Verified Caller IDs have specific limitations compared to Twilio numbers:
  - Cannot be automatically swapped for spam protection
  - Require manual management if flagged
  - Only support outbound calls as caller ID
  - Must be verified through Twilio's process
</Warning>

### Managing Caller ID Status

Caller IDs can have different verification states:

| Status | Description | Actions Available |
|--------|-------------|-------------------|
| **Pending** | Verification in progress | Complete verification process |
| **Verified** | Ready for use | Use for outbound calls |
| **Disabled** | Verification failed or revoked | Re-verify or remove |

## Multiple Numbers per Agent

An agent can have multiple assigned numbers. This is useful for:

- **Volume distribution**: Reduce spam risk
- **Regional segmentation**: Different numbers for different areas
- **Redundancy**: Backup if a number has issues

### How Multiple Numbers Are Used

| Call Type | Behavior |
|-----------|----------|
| **Inbound** | Customer can call any of the numbers |
| **Outbound** | System automatically selects the best available number |

The number with the best **Phone Health** has priority for outbound calls.

## Swap Numbers

You can swap a problematic number for a new one from the Phone Health report:

<Steps>
  <Step title="Open Phone Health">
    Click the health indicator on the agent.
  </Step>
  <Step title="Identify the number">
    Find the number with Warning or Spam status.
  </Step>
  <Step title="Start Swap">
    Click the **Swap** button next to the number.
  </Step>
  <Step title="Confirm">
    The system shows the proposed new number. Confirm the swap.
  </Step>
</Steps>

### What Happens During a Swap

1. **Old number** is unlinked and marked for return
2. **New number** is assigned with **assigned** status
3. Assignment states are updated in real-time

<Info>
  Only Twilio numbers can be swapped automatically. Verified Caller IDs must be managed manually.
</Info>

## Disconnect a Number

To remove a number without replacing it:

1. Open the **Phone Health** report
2. Click **Disconnect** next to the number
3. Confirm the disconnection

<Warning>
  If you disconnect the agent's only number, it won't be able to make or receive calls until you assign another.
</Warning>

## Request New Numbers

To request additional numbers:

1. In the Advanced Editor, Settings section
2. Click **"Request more numbers"**
3. You'll be redirected to the request portal

New numbers are typically available within 24-48 hours.

## Best Practices

### Number Management Workflow

For efficient number management:

<Steps>
  <Step title="Regular Monitoring">
    Check assignment states regularly across all subaccounts.
  </Step>
  <Step title="Credential Management">
    Ensure all subaccounts have proper credentials configured.
  </Step>
  <Step title="Assignment Tracking">
    Use the new assignment states to track number utilization.
  </Step>
  <Step title="Cleanup Operations">
    Use reset and return functions to manage unused numbers.
  </Step>
</Steps>

### Number Rotation

For high-volume campaigns:

1. Assign multiple numbers to the agent
2. The system rotates automatically based on assignment status
3. Monitor Phone Health regularly
4. Swap numbers before they reach "Spam" status

### Caller ID Strategy

For verified Caller IDs:

1. Use for brand recognition and customer trust
2. Monitor spam reports manually
3. Have backup Twilio numbers ready
4. Keep verification status current

### Subaccount Organization

- Use the main account for primary business numbers
- Organize specialized campaigns in separate subaccounts
- Apply consistent naming conventions across subaccounts
- Configure credentials for full management capabilities
- Regularly review and clean up unused numbers using reset/return functions

## FAQ

<AccordionGroup>
  <Accordion title="What's the difference between Twilio numbers and Caller IDs?">
    **Twilio numbers** are fully managed by Meetzy and can be automatically swapped. **Verified Caller IDs** are your own phone numbers that require verification and manual management.
  </Accordion>
  <Accordion title="Can Caller IDs be swapped automatically?">
    No, verified Caller IDs cannot be swapped automatically like Twilio numbers. They require manual management if they become flagged for spam.
  </Accordion>
  <Accordion title="How do I identify Caller IDs in the interface?">
    Caller IDs appear with a 🔒 lock icon and verification status badge, while Twilio numbers show standard management controls.
  </Accordion>
  <Accordion title="What's the difference between reset and return?">
    **Reset** clears a number's configuration but keeps it in your account as unassigned. **Return** completely removes the number from your account and returns it to Twilio's pool.
  </Accordion>
  <Accordion title="Can I recover a returned number?">
    No, returned numbers cannot be recovered. They become available to other Twilio customers.
  </Accordion>
  <Accordion title="What happens if I don't configure subaccount credentials?">
    You can view phone numbers in unconfigured subaccounts but cannot perform management operations like assign, reset, or return.
  </Accordion>
  <Accordion title="How do assignment states help with management?">
    Assignment states provide clear visibility into number utilization and help identify numbers that need attention or can be reset/returned.
  </Accordion>
  <Accordion title="Are numbers exclusive or shared?">
    Each number is exclusive to your account. It's not shared between different Meetzy customers.
  </Accordion>
  <Accordion title="Can I have numbers from different countries on one agent?">
    Yes, you can assign numbers from multiple countries to the same agent.
  </Accordion>
  <Accordion title="Do subaccounts share phone numbers?">
    No, each subaccount maintains its own pool of phone numbers that cannot be shared with other subaccounts.
  </Accordion>
  <Accordion title="How do I move a number between subaccounts?">
    Numbers cannot be moved between subaccounts. You would need to return the number and request a new one in the target subaccount.
  </Accordion>
  <Accordion title="Why does my agent switch to calling only from 400 numbers?">
    As soon as a 400 number is added to the agent's rotation (either manually or by copying from another agent), the agent automatically switches to calling only from its 400 numbers. This is not a manual setting — it's inferred from the numbers in the list.
  </Accordion>
  <Accordion title="Can I add a 400 number myself through self-verification?">
    No. 400 numbers cannot receive the verification call used for self-service numbers. To add a 400 number, open a request to the Meetzy team.
  </Accordion>
  <Accordion title="What happens if the verification code call fails or I miss it?">
    You can simply click **Call me with the code** again from the Outbound numbers panel to request a new call and code.
  </Accordion>
  <Accordion title="Who can enable the 'only 400 numbers' account toggle?">
    This setting is managed exclusively by the Meetzy team at the account level. It is not available as a self-service option in the client dashboard.
  </Accordion>
  <Accordion title="If I copy numbers to another agent, will it affect that agent's calling behavior?">
    It can. If the copied numbers include a 400 number and the target agent didn't have one before, that agent will also start calling only from 400 numbers.
  </Accordion>
  <Accordion title="Why don't I see numbers that other agents are already using in the Add numbers picker?">
    By default, numbers already assigned to other agents in your account are hidden to keep the list simple. Toggle **Show numbers already in use** in the picker to reveal them along with which agents are using them.
  </Accordion>
  <Accordion title="What does Select all 400 do exactly?">
    It checks every available 400 number that isn't already shared with another agent, so you can add a full batch of compliant numbers in one click without manually reviewing each one.
  </Accordion>
  <Accordion title="Can I give my own verified number a custom name?">
    Yes, when verifying your own number you can optionally set a friendly name (e.g. "Main office") so it's easier to recognize later in the rotation list.
  </Accordion>
</AccordionGroup>
